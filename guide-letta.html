🤔 What is Letta?

Letta is an AI agent platform that lets you create and interact with AI agents that have persistent memory. Unlike regular chatbots, Letta agents remember your conversations, preferences, and context across sessions.

💡 Key Difference: Traditional chatbots forget everything after each conversation. Letta agents form "living memories" about themselves, the world, and you—they learn and improve over time.

What Can Letta Agents Do?

  • Remember your preferences, projects, and context
  • Learn from every conversation and improve over time
  • Use tools like web search, memory management, and file operations
  • Maintain persistent knowledge in memory blocks
  • Execute tasks autonomously with access to external APIs

⚠️ Usage Limits: Free tier has limits on message count per day. For heavy usage, consider upgrading to Letta Pro or Max plans which provide:

💡 Bring Your Own Key (BYOK): You can connect your own API keys from OpenAI, Anthropic, or other providers to use premium models with the free tier. Go to Settings → API Keys to add your keys.

🔐 Account Creation

Getting started with Letta takes about 2 minutes:

  1. Visit Letta - Go to app.letta.com in your web browser
  2. Click "Sign Up" - Located in the top-right corner of the homepage
  3. Choose Sign-Up Method:

    Option A: Email

    • Enter your email address
    • Create a secure password
    • Click "Create Account"

    Option B: Google

    • Click "Continue with Google"
    • Select your Google account
    • Grant necessary permissions
  4. Verify Email - Check your inbox for a verification email from Letta. Click the verification link (if you signed up with email)
  5. Log In - Return to app.letta.com and sign in with your credentials
💡 Pro Tip: Use Google sign-up for faster onboarding—no email verification needed!

📥 Import an Agent File (.af)

The fastest way to get started is importing an existing agent file:

  1. Download the Agent File - Get the .af file (e.g., pea-agent.af) from the download section above or from someone sharing an agent with you
  2. Go to Dashboard - Navigate to app.letta.com
  3. Click "Import Agent" - Usually found near the "Create Agent" button at the top of the page
  4. Select the .af File - Click "Choose File" or drag-and-drop the agent file
  5. Review Agent Details - You'll see the agent's name, model, memory blocks, and tools
  6. Click "Import" - The agent will be added to your account
  7. Start Chatting - Click on the imported agent to begin your conversation!
💡 What's in an .af File? Agent files contain:
  • Agent name and description
  • System prompt (agent's instructions)
  • Memory block configurations
  • Tool attachments
  • Model settings
⚠️ Note: Imported agents may need API keys configured if they use external tools. Check Settings → API Keys to add necessary keys.

🛠️ Create Agent from Scratch

Want to build your own agent? Here's how:

  1. Click "Create Agent" - From your dashboard, click the "+ Create Agent" button
  2. Name Your Agent - Give it a descriptive name (e.g., "My Prompt Assistant")
  3. Choose a Model - Select the LLM for your agent:

    Free Tier Models:

    • openai/gpt-4o-mini (recommended for beginners)
    • openai/gpt-4o (more capable)

    Premium Models (BYOK or Pro Plan):

    • anthropic/claude-sonnet-4-5-20250929
    • anthropic/claude-opus-4
    • google/gemini-2.0-flash
  4. Set System Prompt - Write instructions for how the agent should behave. This is the "brain" of your agent.
  5. Add Memory Blocks - Create memory blocks to store persistent information
  6. Attach Tools - Add capabilities like web search, memory management, or custom tools
  7. Click "Create" - Your agent is now ready to use!

Example System Prompt

You are a helpful AI assistant specialized in helping users draft professional emails. ## YOUR ROLE Help users write clear, professional emails for business contexts. ## GUIDELINES - Always ask about the recipient and purpose - Suggest subject lines - Offer tone variations (formal, friendly, direct) - Proofread for clarity and grammar ## MEMORY Remember user preferences about: - Typical tone preference - Common recipients - Signature style

🧠 Memory Blocks Explained

Memory blocks are persistent storage that agents can read and update. They're what make Letta agents truly "remember."

How Memory Blocks Work

  • Memory blocks are always visible to the agent in its context
  • Agents can read memory blocks to recall information
  • Agents can update memory blocks using memory tools
  • Memory blocks persist across all conversations

Standard Memory Blocks

persona

Defines who the agent is, how it behaves, and its core identity. Usually set at creation and not frequently modified.

human

Stores information about the user—their preferences, profile, projects, and anything the agent learns about them.

Custom Memory Blocks

You can create additional memory blocks for specific purposes:

  • prompt_library - Store saved prompts and templates
  • industry_knowledge - Construction terminology, workflows
  • user_preferences - Tone, format, style preferences
  • projects - Current and past project information

Memory Block Properties

  • Label - Name/identifier for the block
  • Value - The actual content stored
  • Limit - Maximum character count (default: varies)
  • Description - What the block is for (helps agent use it correctly)
💡 Best Practice: Always add a description to each memory block. This helps the agent understand when and how to use each block.

🔧 Tools Explained

Tools give agents capabilities beyond just conversation. Here are the main tools available:

Core Memory Tools

core_memory_append

Add new information to a memory block

core_memory_replace

Replace specific text in a memory block

memory_replace / memory_insert

Advanced memory editing operations

Knowledge Tools

conversation_search

Search past conversations for relevant information

archival_memory_insert

Store long-term knowledge in archival memory

archival_memory_search

Search archival memory by semantic similarity

External Tools (If Connected)

web_search

Search the web for current information

run_code_with_tools

Execute Python code with tool access

send_message

Send messages to users or other agents

How Tools Work

When you attach tools to an agent:

  1. The agent sees the tool in its context
  2. The agent can choose to call the tool during conversation
  3. Tool results are added to the conversation context
  4. The agent uses results to improve its response

💬 Conversing with Agents

Once you have an agent (imported or created), here's how to chat:

  1. Select Your Agent - Click on the agent name in your dashboard
  2. Type Your Message - Use the message box at the bottom of the chat interface
  3. Send Message - Press Enter or click Send
  4. Watch the Agent Think - You'll see "reasoning" messages showing the agent's thought process
  5. Read the Response - The agent's reply appears after processing
  6. Continue the Conversation - Keep chatting to build context and memory

What You'll See

  • 🧠 Reasoning - Agent's internal thought process (what it's considering)
  • 🔧 Tool Calls - When the agent uses a tool (like memory or search)
  • 💬 Assistant Message - The actual response to you

First Conversation Tips

For best results, start by introducing yourself:
Hi! I'm [Your Name], and I work as a [Your Role] at [Your Company] in the [Your Industry] industry. I'll be using you to help me with [describe your main use case, e.g., "drafting RFIs, client emails, and project documentation"].

Encouraging Memory Updates

Help the agent remember you better by asking it to save important information:

Please remember that I prefer professional but approachable tone, and I work primarily in residential remodeling. Save this to your memory of me.

📋 Managing Your Agents

Here's how to manage and customize your agents:

View Agent Details

  1. Click on an agent to open it
  2. Click the agent name at the top or look for "Details" or "Settings"
  3. You'll see: System Prompt, Memory Blocks, Tools, Model settings

Edit Memory Blocks

  • Navigate to Memory Blocks section of an agent
  • Click on a block to view/Edit its content
  • Edit the text and save changes
  • Changes are instant—agent will use updated memory on next message

Export an Agent

  • Open the agent details
  • Look for "Export" or "Download as .af"
  • Save the file to share with others or backup

Delete an Agent

  • Open agent details
  • Click "Delete" or "Remove"
  • Confirm deletion
⚠️ Warning: Deleting an agent permanently removes it and all its memory. Export first if you want to preserve it!

📖 Key Terms Glossary

Essential terminology for understanding Letta:

Agent

An AI assistant with memory capabilities. Unlike chatbots, agents maintain state across conversations.

Memory Block

Persistent storage for information. Agents can read and update memory blocks to remember things.

System Prompt

Instructions that define how an agent behaves. The "programming" of the agent's personality and capabilities.

Tool

A capability the agent can use—memory operations, web search, code execution, etc.

Archival Memory

Long-term semantic storage for documents and knowledge. Searchable by meaning, not just keywords.

Reasoning

The agent's internal thought process, visible in Letta to understand how it arrives at responses.

.af File

Agent File format. Contains agent configuration, prompts, memory blocks, and tools for import/export.

ADE

Agent Development Environment. Visual editor for creating and modifying agents.

BYOK

Bring Your Own Key. Use your own API keys from OpenAI, Anthropic, etc. to access premium models.

Context Window

Maximum amount of text the model can process at once. Larger = more context but higher cost.
