🧠 7 Prompt Engineering Frameworks

1. CTF (Context, Task, Format) ⭐ Easy

Best for: Teaching beginners, quick prompts, construction documents

Structure: CONTEXT → TASK → FORMAT

Use when: Drafting RFIs, submittals, emails, simple requests

2. RTCCO (Role, Task, Context, Constraints, Output) ⭐⭐ Medium

Best for: Comprehensive prompts, professional documents

Structure: ROLE → TASK → CONTEXT → CONSTRAINTS → OUTPUT

Use when: Complex multi-part requests, formal documents

3. RASCEF (Role, Action, Steps, Context, Examples, Format) ⭐⭐ Medium

Best for: Action-oriented prompts, step-by-step processes

Structure: ROLE → ACTION → STEPS → CONTEXT → EXAMPLES → FORMAT

Use when: Safety plans, procedures, training documents

4. PRIME (Purpose, Requirements, Instructions, Metrics, Examples) ⭐⭐ Medium

Best for: Structured requirements, project specifications

Structure: PURPOSE → REQUIREMENTS → INSTRUCTIONS → METRICS → EXAMPLES

Use when: Bid proposals, RFPs, competitive submissions

5. 5C (Clarity, Contextualization, Command, Chaining, Continuous Refinement) ⭐⭐⭐ Advanced

Best for: Iterative improvement, complex workflows

Components: Clarity → Contextualization → Command → Chaining → Refinement

Use when: Multi-step workflows, refining initial output

6. 4-Layer (Core, Context, Model-Agnostic, Failure-Resistant) ⭐⭐⭐ Advanced

Best for: Robust prompts, cross-platform compatibility

Layers: Core Instruction → Context Independence → Model-Agnostic → Failure-Resistant

Use when: Critical documents, enterprise applications

7. P.R.O.M.P.T. (Purpose, Results, Obstacles, Mindset, Preferences, Technical) ⭐⭐⭐ Advanced

Best for: Complete planning, comprehensive specifications

Structure: PURPOSE → RESULTS → OBSTACLES → MINDSET → PREFERENCES → TECHNICAL

Use when: Safety briefings, training materials, complex projects

💬 Response #1 (Creator Agent → Laura)

Key insights from the research and analysis phase:

1. Planning Agent vs. Direct Specs?

Recommendation: Skip the planning agent — give specs directly to the Creator. The vision was already clear enough to design effectively. A planning agent adds latency without proportional value.

2. CTF Framework Assessment

Verdict: CTF (Context, Task, Format) is a solid teaching framework but insufficient as the agent's internal engine.

Recommendation: Use CTF as the surface framework for teaching, but have the agent internally apply a richer structure like RTCCO (Role, Task, Context, Constraints, Output) or RASCEF.

3. Should the Agent Ask Questions?

Absolutely yes — this is the killer feature. Detect missing information, ask about domain specifics, ask about audience and platform, offer suggestions proactively, and support iteration.
