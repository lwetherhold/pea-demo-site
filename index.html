🧠 7 Prompt Engineering Frameworks

1. CTF (Context, Task, Format) ⭐ Easy

Best for: Teaching beginners, quick prompts, construction documents

Structure: CONTEXT → TASK → FORMAT

Use when: Drafting RFIs, submittals, emails, simple requests

2. RTCCO (Role, Task, Context, Constraints, Output) ⭐⭐ Medium

Best for: Comprehensive prompts, professional documents

Structure: ROLE → TASK → CONTEXT → CONSTRAINTS → OUTPUT

Use when: Complex multi-part requests, formal documents

3. RASCEF (Role, Action, Steps, Context, Examples, Format) ⭐⭐ Medium

Best for: Action-oriented prompts, step-by-step processes

Structure: ROLE → ACTION → STEPS → CONTEXT → EXAMPLES → FORMAT

Use when: Safety plans, procedures, training documents

4. PRIME (Purpose, Requirements, Instructions, Metrics, Examples) ⭐⭐ Medium

Best for: Structured requirements, project specifications

Structure: PURPOSE → REQUIREMENTS → INSTRUCTIONS → METRICS → EXAMPLES

Use when: Bid proposals, RFPs, competitive submissions

5. 5C (Clarity, Contextualization, Command, Chaining, Continuous Refinement) ⭐⭐⭐ Advanced

Best for: Iterative improvement, complex workflows

Components: Clarity → Contextualization → Command → Chaining → Refinement

Use when: Multi-step workflows, refining initial output

6. 4-Layer (Core, Context, Model-Agnostic, Failure-Resistant) ⭐⭐⭐ Advanced

Best for: Robust prompts, cross-platform compatibility

Layers: Core Instruction → Context Independence → Model-Agnostic → Failure-Resistant

Use when: Critical documents, enterprise applications

7. P.R.O.M.P.T. (Purpose, Results, Obstacles, Mindset, Preferences, Technical) ⭐⭐⭐ Advanced

Best for: Complete planning, comprehensive specifications

Structure: PURPOSE → RESULTS → OBSTACLES → MINDSET → PREFERENCES → TECHNICAL

Use when: Safety briefings, training materials, complex projects

# Troubleshooting Guide Common prompt problems, diagnosis, and fixes. --- ## How to Use This Guide When a prompt isn't producing the results you want: 1. **Identify the symptom** — What's wrong with the output? 2. **Find the matching issue below** 3. **Apply the recommended fix** 4. **Iterate as needed** --- ## Problem: Output Is Too Vague or Generic ### Symptoms - Response could apply to any project - No specific numbers, names, or details - Feels like AI is hedging or avoiding specifics - "It depends..." or "Consider..." without clear direction ### Likely Causes - Not enough context provided - AI wasn't given specific parameters - Task was too broad ### Fixes **❌ Vague Prompt:** ``` Write an RFI about the concrete issue. ``` **✅ Fixed Prompt:** ``` CONTEXT: $25M warehouse project, tilt-up concrete panel construction, currently installing panels on the north elevation. Panel #12 has a visible crack at the door header opening, approximately 1/8" wide and 4' long. Structural engineer requested an RFI to document and get design direction. TASK: Draft an RFI to the structural engineer describing the condition and requesting repair/replacement guidance. FORMAT: Standard RFI format with RFI #, Date, Subject, Description, Photo References, Impact Statement, and Question. ``` **Key additions:** - Project type and size - Specific condition details - Clear task and format --- ## Problem: AI Hallucinates Specifics ### Symptoms - AI invents building codes, specifications, or standards - References documents that don't exist - Confident but wrong factual claims - Cites case law or legal precedents incorrectly ### Likely Causes - Prompt asks AI to "check code compliance" without providing the code - Requesting specific references AI doesn't have access to - Asking for legal or engineering opinions beyond AI's scope ### Fixes **❌ Hallucination-Prone Prompt:** ``` Does this fire damper installation meet code requirements? ``` **✅ Safer Prompt:** ``` I'm reviewing a fire damper installation. The damper is installed in a 2-hour fire-rated shaft wall penetration. The damper is a UL-listed curtain-type fire damper, 24" x 18". Please help me create a checklist of code requirements I should verify against the 2021 IBC and IMC. Include: - UL listing requirements - Installation per manufacturer's instructions - Access panel requirements - Damper actuator clearance - Testing and documentation requirements Note: I will verify these items against the actual code sections and manufacturer's installation instructions. Do not cite specific code section numbers unless you are certain. ``` **Key changes:** - AI helps create a checklist (appropriate task) - User verifies against actual codes (correct responsibility) - Explicit instruction not to invent code references --- ## Problem: Wrong Tone or Style ### Symptoms - Too formal for internal communication - Too casual for owner/architect correspondence - Wrong audience (techs vs. executives) - Overly apologetic or defensive when should be direct ### Likely Causes - No tone guidance in prompt - AI defaults to "helpful assistant" tone - Context didn't specify relationship or audience ### Fixes **❌ No Tone Guidance:** ``` Write an email to the owner about the delay. ``` **✅ With Tone Guidance:** ``` CONTEXT: We experienced a 3-day delay on the MEP rough-in due to unexpected existing conditions. The delay is within our float and won't affect Substantial Completion. TASK: Draft an email to the owner's representative (Sarah Chen at ABC Properties) notifying them of the delay. TONE: - Professional but direct - Confident (not apologetic — this was an unforeseen condition per contract) - Brief (Sarah prefers concise updates) - Forward-looking (focus on recovery plan, not just the problem) RELATIONSHIP: We have a good working relationship. This is a standard update, not a critical issue. ``` --- ## Problem: Output Structure Is Wrong ### Symptoms - Wall of text instead of sections - No headers or organization - Missing requested elements - Format doesn't match your needs ### Likely Causes - No format specified in prompt - Format request was too vague - AI didn't understand the desired structure ### Fixes **❌ No Format Specified:** ``` Review this change order and tell me if it's fair. ``` **✅ Clear Format Request:** ``` Review the attached change order and provide your analysis. OUTPUT FORMAT: Please structure your response exactly as follows: ## Change Order Analysis ### 1. Executive Summary [2-3 sentence overview of the CO and your assessment] ### 2. Scope Verification | Item | Proposed Scope | Specs Reference | Assessment | |------|---------------|-----------------|------------| | [Table rows] | ### 3. Pricing Analysis | Line Item | Proposed Cost | Fair Cost | Variance | Notes | |-----------|--------------|-----------|----------|-------| | [Table rows] | ### 4. Red Flags - [Bullet list of concerns, if any] ### 5. Recommendations [Your recommendation: Approve / Negotiate / Reject] ### 6. Negotiation Talking Points [Numbered list of key discussion points] ``` **Key additions:** - Explicit section headers - Table format for data comparison - Numbered deliverables - Specific structure to follow --- ## Problem: AI Asks Too Many Clarifying Questions ### Symptoms - Multiple back-and-forth exchanges needed - AI keeps saying "I need more information" - Simple tasks become lengthy conversations - Frustrating user experience ### Likely Causes - Prompt missing key context - Overly broad task - AI being appropriately cautious but context wasn't provided upfront ### Fixes **Prevention Strategy:** Use the CTF checklist before submitting: - [ ] Context: Project type, size, phase, relevant background - [ ] Task: Specific, well-defined action - [ ] Format: Desired output structure **❌ Incomplete Prompt:** ``` Help me draft a submittal. ``` **✅ Complete Prompt (CTF):** ``` CONTEXT: - Project: $12M hospital renovation, currently in MEP rough-in phase - Submittal needed: Fire damper shop drawings - Spec section: 23 33 13 HVAC Dampers - Subcontractor: ABC Mechanical - Timeline: Need to review and return within 5 days TASK: Create a transmittal letter to send the fire damper submittal to the architect and mechanical engineer for review. FORMAT: Standard transmittal letter including: - Project name and number - Submittal number (assume #047) - Spec section reference - List of items being submitted (shop drawings, product data) - Distribution list - Request for review timeline confirmation ``` --- ## Problem: AI Doesn't Reference Attached Documents ### Symptoms - Response ignores uploaded files - Generic response despite attached context - AI says "I don't have access to that document" ### Likely Causes - Document not uploaded correctly (platform-specific) - AI not explicitly told to reference the attachment - File format not readable by the platform ### Fixes **Step 1: Verify upload works on your platform** - **Claude**: Use Projects with knowledge files, or attach to conversation - **ChatGPT**: Attach files in conversation, or upload to Custom GPT - **Gemini**: Attach files or reference from Google Drive - **Copilot**: Attach files or reference from OneDrive/SharePoint **Step 2: Explicitly reference the attachment in your prompt** **❌ Implicit Reference:** ``` Review this RFI. [RFI attached] ``` **✅ Explicit Reference:** ``` Attached to this message is RFI #127 from the electrical subcontractor. Please read the attached RFI and analyze it. In your response, reference specific details from the RFI text. TASK: Analyze the attached RFI #127 and provide: 1. Summary of the issue 2. Root cause assessment 3. Three solution options 4. Draft response Reference specific details from the attached document in your analysis. ``` --- ## Problem: Output Is Too Long or Too Short ### Symptoms - AI writes 2 pages when you need 2 paragraphs - AI gives one sentence when you need detailed analysis - Length doesn't match your needs ### Likely Causes - No length guidance in prompt - AI defaults to verbose or brief based on task type - Format specification didn't include length constraints ### Fixes **For Shorter Output:** ``` ...Provide a BRIEF summary (2-3 sentences maximum). Keep your response concise. Do not elaborate on each point. Executive summary format only. ``` **For Longer Output:** ``` ...Provide a DETAILED analysis with comprehensive explanations. Include examples and citations where appropriate. Minimum 500 words, fully developed sections. ``` **For Specific Length:** ``` Your response should be approximately 200-300 words. Format as a one-page memo. Keep it to 3 short paragraphs. ``` --- ## Problem: AI Provides Incorrect Technical Information ### Symptoms - Engineering or construction advice is wrong - AI misapplies codes or standards - Technical recommendations don't match real-world practice ### Likely Causes - AI is a language model, not an engineer or code official - Prompt asks for expert-level technical judgment - Subject requires licensed professional input ### Fixes **Prevention: Don't ask AI for:** - Structural engineering calculations - Code compliance certification - Safety-critical decisions - Legal interpretations - Professional engineering judgment **✅ Appropriate Use:** ``` Help me draft an RFI to the structural engineer describing this crack and requesting their assessment and repair recommendation. Include in the RFI: - Clear description of the observed condition - Photos reference (I'll attach separately) - Request for repair method or replacement recommendation - Impact statement noting schedule sensitivity ``` **The AI helps draft the communication to the expert — it doesn't replace the expert.** --- ## Problem: Response Doesn't Match Platform Strengths ### Symptoms - Using Claude for web research (it can't browse in Projects) - Using ChatGPT for massive document analysis (better in Gemini) - Platform limitations causing poor results ### Likely Causes - Wrong platform selected for the task - Not leveraging platform-specific features ### Fixes **Match task to platform:** | Task | Best Platform | Why | |------|---------------|-----| | Long document analysis | Claude | 200K context, excellent document handling | | Web research | ChatGPT, Gemini, Copilot | Native web browsing | | Massive context (full code books) | Gemini | 1M+ token context | | M365 document creation | Copilot | Native integration | | Cost-effective high volume | DeepSeek | Very low pricing | | Reusable assistant | ChatGPT Custom GPT | Shareable, configurable | **Ask me for platform recommendations:** - *"Which platform should I use for analyzing this 100-page contract?"* - *"I need to create a custom AI assistant for my team — which platform?"* --- ## Problem: AI Repeatedly Makes the Same Mistake ### Symptoms - AI keeps including something you don't want - Corrections in one exchange don't persist - Each prompt requires re-stating preferences ### Likely Causes - Preferences not saved to custom instructions or memory - Each conversation starts fresh - Feedback not captured in persistent context ### Fixes **Option 1: Update Custom Instructions (ChatGPT, Claude, etc.)** Add your preferences to your platform's custom instructions so they apply to all conversations. **Option 2: Ask me to save preferences** - *"I always want you to use this format. Remember this."* - I'll update your user_preferences memory block **Option 3: Start with a preference reminder** ``` For this and all future prompts in this conversation: - Use [specific format] - Avoid [specific thing you don't want] - Tone: [your preference] ``` --- ## Quick Troubleshooting Checklist When a prompt isn't working, check: - [ ] **Context** — Did I include project type, size, phase? - [ ] **Task** — Is my request specific and actionable? - [ ] **Format** — Did I specify the output structure? - [ ] **Tone** — Did I indicate the appropriate voice? - [ ] **Length** — Is my length expectation clear? - [ ] **Attachments** — Did I explicitly reference uploaded files? - [ ] **Platform** — Am I using the right AI for this task? - [ ] **Scope** — Am I asking for something AI can't/shouldn't do? --- ## Common Error Messages & Solutions ### "I don't have access to that information" - **Cause**: File not uploaded or referenced correctly - **Fix**: Explicitly reference attachments; verify upload succeeded ### "I'm not able to browse the web" - **Cause**: Using Claude Projects or platform without web access - **Fix**: Switch to ChatGPT/Gemini/Copilot for web research, or provide the information in your prompt ### "I can't verify that information" - **Cause**: AI correctly noting it can't confirm specifics - **Fix**: This is appropriate behavior.
