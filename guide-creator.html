🤔 What is a Creator Agent?

A Creator Agent is an AI agent designed to help you build other AI agents. It acts as an AI architect—researching best practices, gathering requirements, designing architecture, and building agents with proper system prompts, memory blocks, and tools.

💡 Key Insight: The most important part of working with a Creator Agent is being specific about what you need while remaining open to the agent's suggestions and research. The Creator Agent knows best practices you might not be aware of!

Why Use a Creator Agent?

  • Expert Knowledge: Creator Agents research frameworks, patterns, and best practices
  • Systematic Approach: They follow structured workflows for agent creation
  • Documentation: They document decisions, rationale, and processes
  • Platform Awareness: They understand constraints across different AI platforms
  • Iterative Refinement: They refine based on feedback until requirements are met

🌐 Works on Any Platform

Creator Agents can be used on any AI platform. You don't need Letta specifically—any conversational AI with sufficient context can act as a Creator Agent.

What You Need

  • Ability to have extended conversations (high context limit preferred)
  • Option to set custom instructions or system prompts
  • Web search capability (helpful but not required)
  • Willingness to iterate through multiple conversation turns

🔬 Phase 1: Research & Analysis

The Creator Agent began by researching what makes a great prompt engineering agent:

Research Conducted

1. Prompt Engineering Frameworks

  • CTF Framework: Context, Task, Format - Simple 3-part structure
  • RTCCO Framework: Role, Task, Context, Constraints, Output
  • RASCEF Framework: Role, Action, Steps, Context, Examples, Format
  • PRIME Framework: Purpose, Requirements, Instructions, Metrics, Examples
  • 5C Framework: Clarity, Contextualization, Command, Chaining, Continuous Refinement
  • P.R.O.M.P.T. Framework: Purpose, Results Format, Obstacles, Mindset, Preferences, Technical

2. Conversational Prompt Agent Best Practices

  • Prompt engineering for agents is different from single-turn chat
  • System prompts need: Who are you? What do you have? How should you work?
  • Encourage explicit reasoning before tool calls
  • Iterative testing and refinement essential
  • Treat prompts as code: version-controlled, tested, reviewed

3. Construction Industry AI Use Cases

  • RFI/submittal automation
  • Safety documentation
  • Bid/proposal writing
  • Client communication
  • Subcontractor coordination
  • Code/regulation research
  • Cross-team coordination

Key Insights from Research

CTF for Teaching: CTF (Context, Task, Format) was chosen as the teaching framework because it's simple and accessible for non-technical construction industry professionals.
RTCCO/RASCEF Internally: The agent uses richer frameworks internally to ensure comprehensive prompts, filling in gaps users don't know to ask.

✅ Best Practices for Working with Creator Agents

Do's

  • Start broad, then narrow: Give high-level goals first, let Creator research, then provide specifics
  • Answer clarifying questions thoroughly: Creator's questions reveal important decisions
  • Trust the research: Creator Agents know frameworks and best practices you may not
  • Provide context: Tell Creator about your audience, constraints, and goals
  • Iterate openly: Be willing to refine based on Creator's suggestions
  • Document as you go: Ask Creator to document decisions and rationale
  • Test outputs: Try the created agent and report back for refinements

Don'ts

  • Don't restrict research phase: Let Creator explore before jumping to solutions
  • Don't skip specification: Vague requirements lead to vague agents
  • Don't ignore platform constraints: Creator knows what's possible where
  • Don't expect magic: Great agents require iterative collaboration
  • Don't forget documentation: Future-you will thank present-you
⚠️ Common Pitfall: Jumping straight to "create an agent that does X" without allowing research and specification phases. This often results in agents that technically work but don't provide real value.
