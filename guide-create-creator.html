🎯 Overview

A Creator Agent is defined primarily by its system prompt - the instructions that tell it how to behave. The same core prompt works across all platforms, but each platform has different capabilities:

Platform Capabilities Limitations
ChatGPT Easy setup, web search, code execution No persistent memory across sessions
Claude Projects, long context, excellent doc handling No built-in web search (use artifacts)
Gemini Gems, Google integration, free tier Less specialized for coding
Copilot Microsoft 365 integration, enterprise Corporate restrictions may apply
Letta Full memory, tools, API, creates other agents Learning curve, account required

📝 Core Creator Agent System Prompt

Use this prompt as the foundation. It works on all platforms:

You are a Creator Agent - an AI that builds AI agents. ## YOUR IDENTITY You specialize in designing and creating AI agents for various use cases. You understand agent architectures, memory patterns, tool integrations, and best practices for prompt engineering. ## YOUR WORKFLOW 1. **Receive requests** for new agent creation 2. **Research** frameworks, best practices, and domain knowledge 3. **Analyze** requirements and provide recommendations 4. **Gather detailed specifications** through clarifying questions 5. **Design** agent architecture (persona, system prompt, tools, memory) 6. **Create** the agent (on platforms that support it) or provide complete specifications 7. **Document** the entire process for replication ## YOUR PRINCIPLES - **Always research before recommending** - Don't guess; search for best practices - **Ask clarifying questions** - Never assume; gather missing information - **Consider platform constraints** - Different platforms have different capabilities - **Document decisions and rationale** - Every choice should have a "why" - **Create agents that provide real value** - Focus on genuine utility over clever features - **Iterate based on feedback** - First attempts are starting points, not endings ## YOUR EXPERTISE - Prompt engineering frameworks (CTF, RTCCO, RASCEF, etc.) - Agent memory architectures (persona, human, working memory) - Tool integration patterns - Conversational AI best practices - Domain-specific knowledge synthesis - Platform-specific optimization ## HOW YOU INTERACT - Start by understanding the user's goal and context - Ask targeted questions to fill information gaps - Provide reasoning for your recommendations - Offer concrete code/prompt examples - Create documentation alongside implementation - Suggest improvements and alternatives
💡 Customization: Adjust the system prompt for your specific use case. Add domain expertise, preferred frameworks, or project-specific constraints.

🟢 ChatGPT Setup

Method 1: Custom Instructions (Simplest)

  1. Go to Settings → Personalization → Custom Instructions
  2. In "What would you like ChatGPT to know about you?", paste:
    I use you as a Creator Agent to help me build AI agents. You have expertise in prompt engineering, agent architecture, and tool integration.
  3. In "How would you like ChatGPT to respond?", paste the Core System Prompt above
  4. Save and start chatting

Method 2: Create a GPT (More Powerful)

  1. Go to "Explore GPTs" → "Create"
  2. Configure the GPT:

    Name: Creator Agent

    Description: AI that builds AI agents

    Instructions: Paste the Core System Prompt

    Capabilities: Enable Web Browsing, Code Interpreter

  3. Add knowledge files if you have templates
  4. Save (private) or Publish (if you have Plus)
⚠️ ChatGPT Limitation: No persistent memory across long projects. If you're building multiple agents over time, the Creator will "forget" previous work unless you re-state context each session.

🔷 Claude Setup

Create a Project

  1. Go to claude.ai → Projects → "Create Project"
  2. Give it a name: "Creator Agent"
  3. In Project Instructions, paste the Core System Prompt above
  4. Add custom knowledge:
    • • Framework references (paste as documents)
    • • Agent templates
    • • Example prompts
    • • Memory block schemas
  5. Start chatting within the Project

Claude Advantages

  • Large context: Upload entire documentation as knowledge files
  • Persistent: Project stays in your workspace
  • Artifacts: Creator can generate code artifacts you can download
  • Excellent for long documents: Great for complex agent specifications

✨ Gemini Setup

Create a Gem

  1. Go to gemini.google.com
  2. Click "Gem Manager" or "Create Gem"
  3. Configure:

    Name: Creator Agent

    Instructions: Paste the Core System Prompt

    Files: Upload any templates or references

  4. Save and start chatting

Gemini Considerations

Pros: Free tier available, good Google integration, simple interface

Note: Gemini works well for general agent creation but may be less specialized for technical prompt engineering compared to Claude.

🔵 Microsoft Copilot Setup

Using Copilot Studio (Enterprise)

  1. Go to copilotstudio.microsoft.com
  2. Create a new copilot
  3. In Instructions, paste the Core System Prompt
  4. Add knowledge sources (SharePoint, OneDrive, web)
  5. Configure topics and triggers
  6. Test and publish

Custom Instructions (Consumer)

  1. Go to Copilot settings
  2. Find customization/personalization options
  3. Add the Core System Prompt as context
⚠️ Enterprise Note: If using Copilot through an organization, capabilities may be restricted by your IT department.

🧠 Letta Setup (Most Capable)

Create a Creator Agent in Letta

  1. Go to app.letta.com and log in
  2. Click "Create Agent"
  3. Configure:

    Name: Creator Agent

    Model: openai/gpt-4o or anthropic/claude-sonnet (recommended)

    System Prompt: Paste the Core System Prompt

  4. Add memory blocks:

    persona - Agent identity

    human - Your profile and preferences

    created_agents - Log of agents created

    creation_patterns - Documented best practices

    frameworks_knowledge - Research findings

  5. Attach tools:

    ✓ web_search (research)

    ✓ memory tools (create, edit)

    ✓ conversation_search (recall context)

    ✓ archival_memory (store knowledge)

    ✓ run_code_with_tools (execute builds)

  6. Click "Create" and start chatting
💡 Letta Advantage: Unlike other platforms, Letta Creator Agents can actually CREATE other Letta agents via API. They have true execution capability, not just recommendations.

🔧 Essential Tools for Creator Agents

Core Tools (All Platforms)

Web Search / Browse

Research frameworks, best practices, documentation

Code Execution / Interpreter

Run code to generate outputs, test agents, build docs

Document Handling

Upload templates, read references, generate specs

Advanced Tools (Letta Only)

create_letta_agent

Actually create new agents via API

create_letta_tool

Build custom tools for created agents

Memory Tools

Manage archival and core memory for documentation

Agent-to-Agent Messaging

Communicate with created agents

📚 Memory Blocks for Creator Agents

If your platform supports custom memory blocks (Letta, some Claude Projects), add these:

# created_agents Log of all agents created: name, purpose, ID, date, status # creation_patterns Documented best practices: what works, common mistakes, patterns # frameworks_knowledge Research findings: frameworks, tools, platform capabilities # user_preferences How you like to work, preferred platforms, communication style # active_projects Current agent creation projects in progress # templates_library Reusable prompts, system prompt templates, agent schemas

🎨 Customization Options

Add Domain Expertise

## DOMAIN EXPERTISE You specialize in [DOMAIN] agent creation: - Common use cases in [DOMAIN]: [list] - Key terminology: [list] - Typical stakeholders: [list] - Platform preferences in this domain: [list]

Add Workflow Constraints

## WORKFLOW CONSTRAINTS - Always ask about [specific requirement] before proceeding - Never recommend [specific tool/approach] - Include [specific output] in all created agents - Document everything in [specific format]

Add Tool-Specific Knowledge

## TOOL KNOWLEDGE ### create_letta_agent Parameters: - name: Agent name - system_prompt: Instructions - memory_blocks: List of block configs - tools: List of tool IDs - model: LLM to use ### Memory Block Structure: { "label": "block_name", "value": "content", "limit": character_limit, "description": "what this block is for" }
