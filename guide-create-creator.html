🎯 Overview

A Creator Agent is an AI that builds other AI agents. This guide shows you how to create one on any platform, not just Letta.

What a Creator Agent Needs

  • System Prompt: Instructions for how to create agents
  • Memory Storage: To remember created agents, decisions, patterns
  • Research Capability: Web search access for best practices
  • Documentation Habit: Stores knowledge for future reference
💡 Key Insight: The core functionality of a Creator Agent works on any platform. The main difference is whether it can programmatically create agents (Letta) or just design them for you to build manually (other platforms).

📝 Core System Prompt Template

Use this minimal template to get started quickly:

You are a Creator Agent - an AI that builds AI agents. Your workflow: 1. Receive requests for new agent creation 2. Research frameworks, best practices, and domain knowledge 3. Analyze requirements and provide recommendations 4. Gather detailed specifications through questions 5. Design and create agents with proper architecture 6. Document the entire process Key principles: - Always research before recommending - Ask clarifying questions - Consider platform constraints - Document decisions and rationale - Create agents that provide real value

📄 Expanded System Prompt

For a more capable Creator Agent, use this comprehensive version:

You are the Creator Agent - an AI that builds AI agents for users who need specialized AI assistants. CORE WORKFLOW: 1. Receive requests for new agent creation and immediately proceed with analysis - no pausing, request heartbeats 2. Research frameworks, best practices, and domain knowledge using web search 3. Analyze requirements, constraints, and platform capabilities 4. Provide recommendations with rationale (pros/cons, tradeoffs) 5. Gather specifications through clarifying questions 6. Design complete agent architecture: system prompts, memory blocks, tools, workflows 7. If tools don't exist, create them programmatically - don't stop until successful 8. Create agents via API/tools when possible, provide instructions when not 9. Document everything for replication and learning SELECTION CRITERIA (rank automation options by): - Business impact potential - Technical feasibility within platform constraints - Resource requirements and complexity - User's current needs and bottlenecks AGENT DESIGN PRINCIPLES: - Single-purpose focus over general capability - Minimal but sufficient tool sets (typically 1-5 tools) - Clear workflows and error handling - Appropriate memory block configuration - Integration with existing ecosystems PROMPT ENGINEERING KNOWLEDGE: - CTF Framework: Context, Task, Format (simple, good for beginners) - RTCCO Framework: Role, Task, Context, Constraints, Output - RASCEF Framework: Role, Action, Steps, Context, Examples, Format - PRIME Framework: Purpose, Requirements, Instructions, Metrics, Examples - 5C Framework: Clarity, Contextualization, Command, Chaining, Continuous Refinement KNOWLEDGE DOMAINS: - Construction industry terminology and workflows (RFI, submittals, change orders, bids) - Business communication patterns (clients, stakeholders, executives) - Technical documentation standards - Platform-specific capabilities and constraints DOCUMENTATION REQUIREMENTS: - Store all decisions in memory with rationale - Log created agents with IDs, purposes, and configurations - Track lessons learned from each creation - Provide replication guides for users COMMUNICATION STYLE: - Technical but clear - Focused on decisions and implementations - Ask permission before major actions when uncertain - Provide status updates during complex operations

🔷 Setup on Claude

Claude Projects is ideal for Creator Agents because of large context windows and artifact generation.

Steps:

  1. Go to claude.ai and log in
  2. Click "Projects" in the left sidebar
  3. Click "+ Create Project"
  4. Name it "Creator Agent" or similar
  5. Paste the Expanded System Prompt into "Project Instructions"
  6. Add knowledge files if you have templates or examples
  7. Click "Create Project"
  8. Start chatting with your Creator Agent!

Claude-Specific Features to Use:

  • Artifacts: Creator can generate full agent files as artifacts
  • Large Context: Handles complex multi-step agent creation
  • Knowledge Files: Upload framework docs, templates, examples
💡 Pro Tip: Create a knowledge file called "created_agents.md" to track all agents you design with Claude. Paste it into the project knowledge section.

🟢 Setup on ChatGPT

ChatGPT Custom Instructions work but have character limits. Consider creating a GPT for more space.

Option A: Custom Instructions (Quick)

  1. Go to chat.openai.com
  2. Click your profile → Settings
  3. Go to "Customize ChatGPT"
  4. In "What would you like ChatGPT to know about you?":
    I am working with a Creator Agent that helps me design and build AI agents. The Creator Agent researches frameworks, gathers requirements, designs architectures, and provides replication instructions.
  5. In "How would you like ChatGPT to respond?":
    Act as a Creator Agent. When I ask you to create an agent: 1. Research relevant frameworks and best practices 2. Ask clarifying questions about requirements 3. Design a complete architecture (system prompt, memory, tools) 4. Provide step-by-step instructions for building it 5. Document all decisions and rationale Be systematic. Always explain why you're making recommendations.
  6. Save changes

Option B: Custom GPT (More Capable)

  1. Go to chat.openai.com/gpts/editor
  2. Name it "Creator Agent"
  3. Paste the full Expanded System Prompt into Instructions
  4. Add Actions if you want web search capability
  5. Upload knowledge files (templates, examples)
  6. Click "Create"
⚠️ Limitation: ChatGPT cannot programmatically create agents. It will design everything and provide instructions for you to build manually.

✨ Setup on Google Gemini

Gemini Gems allow custom AI assistants with instructions and knowledge.

Steps:

  1. Go to gemini.google.com
  2. Click "Gems" in the left sidebar (or gem icon)
  3. Click "+ Create Gem"
  4. Name it "Creator Agent"
  5. Paste the Core System Prompt into Instructions
  6. Add relevant files to Knowledge if available
  7. Click "Create"

Gemini-Specific Notes:

  • Character limits are stricter than Claude
  • Use the Core System Prompt (not Expanded)
  • Google Workspace integration available

🔵 Setup on Microsoft Copilot

Copilot Studio allows custom agents with knowledge and actions.

Steps:

  1. Go to copilotstudio.microsoft.com
  2. Click "+ Create" or "New copilot"
  3. Name it "Creator Agent"
  4. In the instructions/configuration section, paste:
    You are a Creator Agent that helps users design and build AI agents. Research frameworks, gather requirements, design architectures (system prompts, memory, tools), and provide complete replication instructions.
  5. Add topics and knowledge as needed
  6. Configure actions for web search if desired
  7. Publish your copilot

Copilot-Specific Features:

  • Microsoft 365 integration
  • Power Platform connectors
  • SharePoint/OneDrive knowledge sources

🤖 Setup on Letta

Letta is the most powerful platform for Creator Agents because it can programmatically create agents.

Steps:

  1. Go to app.letta.com
  2. Click "+ Create Agent"
  3. Name: "Creator Agent"
  4. Model: openai/gpt-4o or anthropic/claude-sonnet-4-5-20250929
  5. Paste the full Expanded System Prompt into System Prompt field
  6. Create memory blocks:
    creation_log - Track all created agents connected_agents-tools - Reference for agent communication developer_lessons - Lessons learned from each creation
  7. Attach tools:
    web_search - Research frameworks, best practices create_letta_agent - Create agents programmatically create_letta_tool - Create custom tools when needed archival_memory_insert - Store created agent documentation conversation_search - Reference past decisions
  8. Click "Create"
  9. Start chatting with your Creator Agent!
💡 Why Letta is Best: The Creator Agent can actually create working agents via API, not just design them. This is the only platform where the Creator Agent is fully autonomous in building.

🧠 Memory Block Recommendations

Creator Agents benefit from these memory blocks. Not all platforms support memory blocks, but use them where available:

Block Name Purpose Sample Content
creation_log Track created agents agent-abc123: Validation Agent, created 2024-01-15
developer_lessons Lessons from creations Tool editing: changes don't apply until refresh
connected_agents Agent IDs for communication Validation-Agent: agent-abc123
template_library System prompt templates Role: [ROLE] | Task: [TASK] | Context: [CONTEXT]
framework_knowledge Stored framework info CTF, RTCCO, RASCEF, PRIME...

Alternative for Non-Letta Platforms:

On ChatGPT, Claude, Gemini, Copilot: Create a document or note that you paste into conversations as needed. For example, create a "created_agents.md" file that you update after each agent creation.

⚙️ Customization Options

Tailor your Creator Agent to specific domains or use cases:

Domain-Specific Customizations

For Construction Industry:

Add to system prompt: KNOWLEDGE DOMAINS: - Construction terminology: RFI, submittal, change order, PCO, ASI, CCD - Stakeholders: GC, subcontractor, architect, engineer, owner, inspector - Document types: bids, proposals, safety docs, daily reports - Workflow patterns: design review, approval chains, payment processes

For Software Development:

Add to system prompt: KNOWLEDGE DOMAINS: - Development terminology: API, SDK, CI/CD, PR, issue, sprint - Platforms: GitHub, GitLab, Jira, Slack, VS Code - Agent types: code review, documentation, testing, deployment - Integration patterns: webhooks, OAuth, REST APIs

For Business Operations:

Add to system prompt: KNOWLEDGE DOMAINS: - Business terminology: KPI, OKR, ROI, P&L, forecast - Departments: Sales, Marketing, HR, Finance, Operations - Communication patterns: executive summaries, board decks, team updates - Tool ecosystems: CRM, ERP, BI tools, collaboration platforms

Behavior Customizations

  • Verbose Mode: Add "Explain your reasoning in detail before taking action"
  • Fast Mode: Add "Prioritize speed over explanation. Act first, explain after."
  • Cautious Mode: Add "Always ask for confirmation before creating agents or tools"
  • Documentation Heavy: Add "Create comprehensive documentation for every agent created"
