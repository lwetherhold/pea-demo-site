🤖 Creator Agent Overview

A Creator Agent is an AI agent specifically designed to help you build other AI agents. It acts as an AI architect—researching, designing, and building agents with proper system prompts, memory, and tools.

What a Creator Agent Does

  1. Research - Investigates frameworks, best practices, and domain knowledge
  2. Analyze - Evaluates requirements and provides recommendations
  3. Design - Creates agent architecture (prompts, memory, tools)
  4. Build - Creates the actual agent on the target platform
  5. Document - Records decisions, rationale, and processes
  6. Iterate - Refines based on feedback

Core Capabilities Needed

ReasoningComplex analysis
CreationBuild outputs
IterationRefine based on feedback

🟢 ChatGPT Setup

Creating a Creator Agent in ChatGPT using Custom Instructions:

Method 1: Custom Instructions (Free & Plus)

  1. Open Settings - Click your profile → Settings
  2. Go to Customization - Select "Custom Instructions"
  3. Field 1: "What would you like ChatGPT to know about you?"
    I use ChatGPT to create other AI agents. I want it to research best practices, ask clarifying questions, design agent architecture, and help me build agents for various platforms.
  4. Field 2: "How would you like ChatGPT to respond?"
    [Paste the Core System Prompt Template from above]
  5. Save - Click Save changes

Method 2: Create a GPT (Plus only)

  1. Go to Explore - Click "Explore GPTs" in sidebar
  2. Create GPT - Click "+ Create"
  3. Configure Tab:
    • Name: "Creator Agent"
    • Description: "AI architect that builds AI agents"
    • Instructions: Paste full system prompt
    • Capabilities: Enable Web Browsing
  4. Save - Click Save and choose who can access

ChatGPT Limitations

⚠️ Note: ChatGPT Custom Instructions are limited in character count. Use the GPT builder for longer prompts. No persistent memory between sessions unless using Projects (Plus feature).

🔷 Claude Projects Setup

Claude Projects offer the best environment for Creator Agents due to long context and project features:

Creating a Creator Agent Project

  1. Go to Claude - Visit claude.ai
  2. Create Project - Click "+ Create Project" in sidebar
  3. Name Project - "Creator Agent" or similar
  4. Add Project Instructions:
    [Paste the full Core System Prompt Template from above]
  5. Add Knowledge Files (Optional):
    • Upload framework documentation
    • Add example agent prompts
    • Include platform capability guides
  6. Start Creating - Begin conversation within the project

Claude Advantages

✅ Why Claude is Excellent for Creator Agents:
  • 200K context window - Handle complex research and long outputs
  • Project persistence - All context saved within project
  • Knowledge files - Upload reference documents
  • Artifacts - Generate and display code cleanly

✨ Gemini Gems Setup

Google's Gemini offers Gems as customizable AI assistants:

Creating a Creator Agent Gem

  1. Go to Gemini - Visit gemini.google.com
  2. Gem Manager - Click "Gem Manager" or "+ New Gem"
  3. Name Your Gem - "Creator Agent"
  4. Add Instructions:
    [Paste the Core System Prompt Template]
  5. Save - Click Save Gem
  6. Use - Click on your Gem to start creating agents

Gemini Features

  • Gem persistence: Instructions saved across sessions
  • Google integration: Access to Google Search and Workspace
  • Long context: Gemini 1.5 Pro has 1M+ token context

🔵 Microsoft Copilot Setup

Copilot has limited customization compared to other platforms:

Option 1: Copilot Pro - Custom Instructions

  1. Go to Copilot - Visit copilot.microsoft.com
  2. Settings - Click settings/manage
  3. Custom Instructions - Add creator agent context
  4. Save - Apply settings

Option 2: Copilot Studio (Business)

  1. Access Copilot Studio - copilotstudio.microsoft.com
  2. Create Agent - New conversational agent
  3. Add Topics - Research, Design, Build, Document
  4. Add Knowledge - Upload reference documents
  5. Publish - Deploy to your organization
⚠️ Copilot Limitations: Less flexible for custom agent creation. Best for Microsoft 365 integrated workflows. Copilot Studio requires business license.

🧠 Letta Agent Setup

Letta provides the most powerful environment for Creator Agents with persistent memory and tool access:

Creating a Creator Agent in Letta

  1. Go to Letta - Visit app.letta.com
  2. Create Agent - Click "+ Create Agent"
  3. Basic Configuration:
    • Name: Creator Agent
    • Model: openai/gpt-4o or claude-sonnet-4-5
  4. System Prompt - Paste the Core System Prompt Template
  5. Add Memory Blocks - See Recommended Memory Blocks below
  6. Attach Tools - See Essential Tools below
  7. Create - Click Create Agent

Letta Advantages

✅ Why Letta is Ideal for Creator Agents:
  • Memory blocks: Persistent storage for created agents and decisions
  • Tool access: Web search, code execution, file operations
  • Agent creation: Can actually create other Letta agents via API
  • Self-documenting: Built-in memory tools for recording process

🧠 Recommended Memory Blocks

If your platform supports memory blocks (Letta), add these:

Core Blocks

persona Description: Creator Agent identity and workflow Content: Who I am, my workflow, how I approach agent creation human Description: User information Content: User's name, preferences, types of agents they want to create created_agents Description: Log of all agents created Content: Agent names, IDs, purposes, creation dates, status creation_log Description: Detailed creation history Content: What was created, how, why, decisions made, lessons learned best_practices Description: Accumulated knowledge about agent creation Content: Frameworks, patterns, platform specifics, dos and don'ts

Optional Advanced Blocks

platform_knowledge Description: Platform-specific capabilities and limitations Content: What each AI platform can/cannot do, tool availability template_library Description: Reusable agent templates Content: Common agent patterns, starter prompts, configurations user_feedback Description: Feedback on created agents Content: What worked, what didn't, improvements requested

🔧 Essential Tools

Creator Agents benefit from these capabilities:

Research Tools

Web Search

Essential for researching frameworks, best practices, and platform capabilities. Look for: "web_search" tool or built-in browsing.

Memory Tools

Persistent Storage

For storing created agents, decisions, and templates. Look for: memory blocks, knowledge files, or project context.

Code Execution

Run Code

For building websites, testing outputs, and working with APIs. Look for: "run_code_with_tools", "code interpreter", or similar.

Document Tools

File Access

For reading templates, examples, and saving outputs. Look for: file upload/download, GitHub integration.

💡 Platform Tool Availability:
  • ChatGPT: Web Browsing, Code Interpreter, File Upload
  • Claude: Artifacts (code display), Knowledge Files
  • Gemini: Google Search, Workspace integration
  • Letta: Full tool library including memory, code, search

⚙️ Customization Options

Customize your Creator Agent based on your needs:

Domain Specialization

Add domain knowledge to the system prompt:

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ DOMAIN KNOWLEDGE: [CONSTRUCTION / FINANCE / HEALTHCARE / TECH] ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ - Industry terminology - Common workflows - Regulatory considerations - Stakeholder types - Document types commonly used

Creation Style

Choose your creation approach:

  • Methodical: Research → Analyze → Design → Build → Test
  • Rapid Prototyping: Quick first drafts, then refine
  • Collaborative: Check in at each phase for approval
  • Autonomous: Full creation cycle, report back when done

Output Preferences

Define how you want outputs:

  • Format: Complete prompts vs. outlines vs. both
  • Detail level: Brief summaries vs. comprehensive documentation
  • Code style: Copyable blocks vs. downloadable files

🧪 Testing Your Creator Agent

Once you've set up your Creator Agent, test it:

Test Prompt #1: Basic Agent

Create a simple email drafting agent for me. I work in [your industry] and need help writing professional emails to clients.

Test Prompt #2: Complex Agent

Create a comprehensive project management assistant that can help me track tasks, manage deadlines, and coordinate with my team. It should work on [platform].

Test Prompt #3: Domain-Specific

Create an agent specialized in [your domain] that can help with [specific tasks]. The agent should understand [industry terminology] and work well with [stakeholders].

What to Evaluate

  • Research: Does it research before proposing solutions?
  • Questions: Does it ask clarifying questions?
  • Output: Are outputs complete and usable?
  • Documentation: Does it document decisions and rationale?
  • Iteration: Does it refine based on feedback?
💡 Refinement: If the Creator Agent isn't meeting expectations, add more specific instructions to the system prompt. Iterate until it produces the behavior you want.
