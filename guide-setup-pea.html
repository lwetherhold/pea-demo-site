⚡ Quick Start

Get PEA running in Letta in under 5 minutes:

  1. Import PEA - Download pea-agent.af and import via Letta dashboard
  2. Open PEA - Click on the imported agent to start chatting
  3. Introduce Yourself - PEA will ask about your name, company, role, and preferences
  4. Request Your First Prompt - Ask PEA to help draft any prompt for any platform
Example first request: "Help me write a prompt for ChatGPT to draft an RFI about a beam conflict. My project is commercial TI, and I need to ask the structural engineer about clearance issues."

💬 First Conversation Flow

When you first start chatting with PEA, here's what to expect:

Step 1: Initial Setup Questions

PEA: Hi! I'm ready to help you craft effective prompts for any AI platform.

Let me learn a bit about you:

  1. What's your name and company?
  2. What's your role in construction? (GC, subcontractor, architect, etc.)
  3. Which AI platform do you use most? (ChatGPT, Claude, Gemini, Copilot)
  4. Do you prefer professional or casual communication?
  5. What do you typically use AI for? (RFIs, bids, emails, reports, etc.)

Step 2: Your Response Example

You: I'm John Martinez, project manager at ABC Construction. We do mostly commercial TI work. I use ChatGPT mostly for RFIs and client emails. I prefer professional but approachable tone—nothing too stiff.

Step 3: PEA Stores & Confirms

PEA: Got it, John! I've saved your preferences:

  • Company: ABC Construction
  • Role: Project Manager
  • Project types: Commercial TI
  • Platform: ChatGPT
  • Tone: Professional but approachable
  • Common tasks: RFIs, client emails

What would you like to work on first?

💡 Why This Matters: PEA stores your preferences so every prompt is tailored to your context. Next time, it remembers your tone, project types, and platform preferences.

🎯 Capabilities & Features

Core Capabilities

  1. Casual Input Processing - Takes brain dumps, voice-to-text, rough notes
  2. Framework Application - Uses CTF for teaching, RTCCO internally
  3. Platform Optimization - Adapts prompts for ChatGPT, Claude, Gemini, Copilot, DeepSeek
  4. Iterative Refinement - "Make it shorter", "More professional", "Add more detail"
  5. Educational Explanations - Explains why certain elements included
  6. Prompt Library - Saves and recalls your favorite prompts
  7. Transfer Capability - Generates export formats for other platforms
  8. Migration Assistance - Helps move context between AI platforms
  9. Construction Awareness - Knows RFI, submittal, bid, change order workflows

How PEA Uses Frameworks

CTF (Context, Task, Format) - Simpler framework PEA uses to explain prompt structure to beginners

RTCCO/RASCEF - Richer framework PEA uses internally to ensure comprehensive prompts, filling gaps you might not know to ask about

🚀 Using PEA Effectively

Best Practices

  1. Provide Context Up Front - "I'm drafting an RFI" is better than "Write me a prompt"
  2. Specify Target Platform - "This is for ChatGPT" or "For Claude"
  3. Include Key Details - Who receives it, what you need, any constraints
  4. Iterate Freely - Use "Make it..." requests to refine
  5. Ask for Explanations - "Why did you include that element?"
  6. Save Good Prompts - "Add this to my prompt library"

Refinement Prompts

"Make it shorter" "Make it more professional" "Add more technical detail" "Make it for someone unfamiliar with construction" "Add a section for attachments" "Change tone to be friendlier" "Format as bullet points instead" "Add a deadline request"

📝 Example Prompts

RFI Drafting

User: I need a prompt for ChatGPT to draft an RFI about a ductwork conflict. The mechanical drawings show ducts at 8' AFF but the structural drawings show a beam at 7'6" AFF in the same location.

PEA: Here's a prompt optimized for ChatGPT:

You are helping draft an RFI for a construction project. CONTEXT: - Project type: [Commercial TI] - Issue: Ductwork/beam conflict - Mechanical drawings: Ducts at 8' AFF - Structural drawings: Beam at 7'6" AFF - Conflict location: Same coordinates DRAFT AN RFIthat: 1. Clearly identifies the discrepancy 2. References specific drawing sheets 3. Asks: What is the intended resolution? 4. Requests: Clarification before [DATE] to avoid schedule impact FORMAT: Professional RFI with project header, question body, and suggested resolution if applicable.

Bid Proposal

Request: "Help me write a prompt for Claude to draft a lump sum bid proposal for a restaurant TI project" PEA generates platform-optimized prompt with sections for executive summary, scope of work, schedule, key personnel, safety approach, and pricing.

Client Email

Request: "Write a prompt for ChatGPT to email a client about a schedule delay due to material lead time" PEA creates prompt with: situation description, impact explanation, mitigation efforts, and clear request for direction.

📤 Transfer to Other Platforms

PEA can generate export formats for other AI platforms:

Requesting Transfer

"Help me transfer you to Claude. Generate the system prompt and instructions for a Claude Project."
"Export my preferences and prompt library so I can use them in ChatGPT Custom Instructions."

What PEA Provides

  1. Platform-Optimized System Prompt - Adapted for target platform's capabilities
  2. Memory Block Contents - Your preferences, templates, etc.
  3. Setup Instructions - Step-by-step for that platform
  4. Limitations Note - What won't transfer (tools, persistent memory)
⚠️ Note: Not all capabilities transfer. Letta's persistent memory and tools won't be available on ChatGPT or Claude, but your preferences and prompt templates will.

🔀 Migration Assistance

PEA helps migrate context between AI platforms:

ChatGPT → Claude

Request: "I'm switching from ChatGPT to Claude. Help me migrate my context and preferences."

PEA generates a context.md file format that captures your preferences, typical workflows, and prompt history for pasting into Claude Projects.

Available Migration Paths

  • ChatGPT → Claude
  • ChatGPT → Gemini
  • ChatGPT → Copilot
  • Claude → ChatGPT
  • Claude → Gemini
  • Gemini → ChatGPT

🔧 Troubleshooting

Common Issues

Issue: PEA asks too many questions

Solution: Provide more context upfront. Say "Just give me a draft" if you want quick output.

Issue: Prompts are too long

Solution: Use "Make it shorter" or "Condense to 3 sentences"

Issue: PEA forgot my preferences

Solution: Remind PEA: "Remember that I prefer professional tone for client communications" - it will save to memory.

Issue: Prompt doesn't work on my platform

Solution: Specify platform more clearly: "Generate this for Claude" or "This is for ChatGPT"

Getting Better Results

  • Provide examples: "Here's an RFI I wrote before..."
  • Specify audience: "This is for an architect" vs "for a client"
  • Include constraints: "Must be under 200 words" or "Need response by Friday"
  • Iterate: Don't expect perfection on first try
