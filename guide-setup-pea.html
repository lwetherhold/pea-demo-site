📥 Importing the PEA

Get the Prompt Engineering Agent running in your Letta account:

Option 1: Import Agent File

  1. Download pea-agent.af - From the demo site or SDSU AI Club
  2. Go to Letta - Visit app.letta.com
  3. Import Agent - Click "Import Agent" button
  4. Select File - Choose the downloaded pea-agent.af
  5. Review - Check agent details appear correct
  6. Import - Click Import to add to your account

Option 2: Create from Template

If you don't have the .af file, create manually:

  1. Create Agent - Click "+ Create Agent" in Letta
  2. Name: PEA (Prompt Engineering Agent)
  3. Model: openai/gpt-4o or claude-sonnet-4-5
  4. System Prompt: Copy from Agent Transfer tab on demo site
  5. Memory Blocks: Add the 20 blocks documented below
  6. Tools: Attach memory, search, and web tools
  7. Create - Finalize agent creation
⚠️ Important: After importing, send your first message to trigger the PEA's self-initialization. It will set up its memory blocks automatically.

💬 First Conversation Flow

When you first chat with the PEA, it will ask questions to personalize your experience:

Initial Setup Questions

  1. Your Name & Company - Who you are and where you work
  2. Your Role - GC, subcontractor, architect, engineer, owner, etc.
  3. Preferred AI Platform - ChatGPT, Claude, Gemini, Copilot, or other
  4. Communication Style - Professional or casual tone preference
  5. Typical Use Cases - RFIs, emails, bids, safety docs, etc.
  6. Industry Focus - Residential, commercial, industrial, TI, etc.

Example First Message to Send

Hi! I'm ready to get started with prompt engineering. My name is [Your Name] and I work at [Company Name] as a [Your Role]. I typically use [ChatGPT/Claude/Gemini] for AI assistance. I prefer [professional/casual] communication, and I mainly need help with [describe your top 3 use cases like "drafting RFIs, client emails, and bid proposals"].

What PEA Will Do

After your introduction, PEA will:
  • Store your profile in memory
  • Adapt its communication to your style
  • Prepare platform-specific knowledge
  • Load relevant templates for your industry
  • Ask any clarifying questions

🧠 All Memory Blocks (20 Total)

The PEA uses 20 memory blocks organized into 4 categories:

📦 Core Identity (4 blocks)

persona

Agent identity: Who PEA is, its role, personality, and core behaviors.

human

User profile: Name, company, role, preferences, communication style.

guardrails

Boundaries: What PEA will/won't do, ethical guidelines, limitations.

welcome_message

First interaction guide: How PEA introduces itself and gathers info.

📚 Frameworks & Knowledge (5 blocks)

frameworks

CTF, RTCCO, RASCEF, PRIME, 5C frameworks with explanations.

construction_glossary

Industry terminology: RFI, submittal, change order, NTP, GMP, etc.

platform_knowledge

ChatGPT, Claude, Gemini, Copilot, DeepSeek capabilities and formats.

construction_templates

Templates for RFIs, submittals, change orders, bids, emails.

prompt_library

Saved prompts: User's favorite prompts, templates, and examples.

📖 Guides & Examples (4 blocks)

transfer_formats

Platform-specific export formats for moving PEA to other AI platforms.

migration_templates

Prompts for migrating between AI platforms (ChatGPT → Claude, etc.).

troubleshooting_guide

Common issues and solutions for prompt engineering.

examples_showcase

Before/after examples demonstrating effective prompt engineering.

⚡ Working Memory (6 blocks)

user_preferences

Tone, format, detail level preferences extracted from conversations.

active_context

Current project or task the user is working on.

scratchpad

Temporary workspace for building and refining prompts.

session_log

Current session activity and decisions made.

lessons_learned

What works/doesn't work for this user over time.

maintenance_log

Updates, fixes, and improvements to the agent.

💡 Auto-Initialization: When PEA receives its first message, it automatically populates these memory blocks using the memory tool. You don't need to manually set them up.

📋 Example Use Cases

The PEA is designed for construction industry professionals:

1. Draft an RFI

"I need an RFI about a conflict between the structural drawings and MEP coordination. Send to the architect."

PEA will ask: - What type of project? - Specific location/area? - What's the conflict in detail? - Schedule impact? - Response deadline? Then generates: Professional RFI with all required fields

2. Write a Change Order Email

"I need to tell the owner about a necessary change order for additional waterproofing."

PEA will ask: - Why is it needed? - Cost impact? - Schedule impact? - Who authorized discovery? Then generates: Clear, professional email with options

3. Prepare a Bid Proposal

"Help me write a lump sum bid proposal for a TI project."

PEA will ask: - Project scope highlights? - Your approach/methodology? - Key personnel? - Schedule duration? - Any exclusions to note? Then generates: Complete proposal structure with sections

4. Create a Safety Briefing

"I need a toolbox talk about fall protection for next week."

PEA will ask: - Any recent incidents to reference? - Crew type/size? - Specific work area/equipment? - Duration desired? Then generates: Talk outline with hazards, mitigations, Q&A prompts

5. Client Communication

"Email the owner about a 3-week schedule delay due to material issues."

PEA will ask: - Cause specifics? - Mitigation efforts? - New completion date? - What do you need from them? Then generates: Transparent, solution-oriented email

🔄 Typical Workflow

How to work with PEA on any prompt engineering task:

  1. Describe Your Need - "I need [document type] for [purpose] to send to [recipient]"
  2. Answer Questions - PEA asks clarifying questions about context
  3. Review Draft - PEA generates prompt or document
  4. Request Changes - "Make it more formal" or "Add the budget section"
  5. Iterate - Continue refining until satisfied
  6. Save to Library - "Save this prompt for future use"
  7. Learn - PEA remembers what works for you

Refinement Commands

  • "Make it shorter" - Condense the output
  • "More professional" - Elevate tone
  • "More casual" - Friendly tone
  • "Add [element]" - Include additional content
  • "Remove [element]" - Take out content
  • "Format as [bullets/table/paragraph]" - Change structure
  • "Explain why you included [X]" - Educational insight

🏗️ Construction-Specific Features

PEA is tailored for BIA SCC AI Subcommittee members:

Document Types Supported

  • RFI - Request for Information
  • Submittals - Product data, shop drawings
  • Change Orders - Owner notifications, pricing
  • Bid Proposals - Lump sum, GMP, cost-plus
  • Daily Reports - Field documentation
  • Safety Documents - JHA, toolbox talks, incident reports
  • Client Emails - Status updates, issue notifications
  • Subcontractor Letters - Coordination, notices

Industry Terminology Known

RFI - Request for Information ASI - Architect's Supplemental Information CCD - Construction Change Directive PCO - Potential Change Order NTP - Notice to Proceed GMP - Guaranteed Maximum Price DB - Design-Build DBB - Design-Bid-Build CMAR - Construction Manager at Risk TI - Tenant Improvement GC - General Contractor Sub - Subcontractor A/E - Architect/Engineer

Stakeholder-Aware

PEA adjusts style based on recipient:

  • Owners: Business-focused, clear cost/schedule impact
  • Architects: Technical, references drawings/specs
  • Subcontractors: Direct, actionable instructions
  • Inspectors: Compliance-focused, documentation

📤 Transfer to Other Platforms

PEA can help you use it on your preferred AI platform:

Transfer Prompt

Help me transfer you to [Claude/ChatGPT/Gemini/Copilot]. Give me: 1. The system prompt formatted for that platform 2. Step-by-step setup instructions 3. Any limitations or workarounds 4. How to verify it's working

  • Gemini: Gem instructions
  • Copilot: Copilot Studio configuration
  • DeepSeek: Conversation starter context

🔀 Platform Migration Help

PEA can help you migrate between AI platforms:

Migration Prompt

I want to migrate from [current platform] to [target platform]. My main use is [describe use cases]. Help me: 1. Export my context from [current platform] 2. Format it for [target platform] 3. Set up [target platform] with my preferences 4. Verify the migration worked

Common Migrations

  • ChatGPT → Claude: Transfer Custom Instructions to Project Instructions
  • Claude → ChatGPT: Split Project context into Custom Instructions fields
  • ChatGPT → Gemini: Convert prompts to Gem format

⚙️ Configuration Options

Format Preference

Detail Level

Provide [brief/medium/detailed] explanations. I want to understand [just the output / the reasoning too].

Platform Default

Industry Focus

💡 Persistence: PEA remembers these preferences in its memory blocks. You only need to set them once.

🔧 Troubleshooting

Common issues and solutions:

PEA Asks Too Many Questions

Solution: Say "I'll provide all details upfront" then give complete context in one message. PEA will adapt to your style.

Output isn't in the Right Format

Solution: Be explicit: "Format as [specific format]" or provide an example of what you want.

PEA Doesn't Remember Preferences

Solution: Say "Please save this preference to your memory" after stating what you want remembered.

Prompt Doesn't Work on My Platform

Solution: Tell PEA which platform you're using: "Rewrite this for [ChatGPT/Claude/Gemini] specifically."

Need to Start Fresh

Solution: Say "Let's reset. I want to update my preferences" to have PEA re-gather your information.

Agent Seems Slow

Solution: This is normal - PEA is using tools to search memory and update contexts. The reasoning process produces better results.
